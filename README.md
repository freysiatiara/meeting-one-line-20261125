Entry for the make.fun bounty [The Meeting That Should Have Been One Line](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c): write the single sentence that could have replaced an entire pointless meeting.

## The line

> Update: nothing changed, nothing is blocked, and this meeting is the only thing blocking my afternoon.

## How it works

`main.py` (standard library only) writes that one line to `/output/entry.txt`
(or the path resolved from `ENTRY_OUTPUT`, `OUTPUT_DIR`, or
`MAKEFUN_OUTPUT_DIR`). Run it with:

```sh
python3 main.py
```
